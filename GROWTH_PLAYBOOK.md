# Kreatif growth playbook (indie artists + art fans)

## Positioning (one line)
**Spotify is for listening. Instagram is for images. Kreatif is for when the song and the art belong together.**

## The loop we own
1. Fan discovers a **pair** or a work on Home (New / Rising / Pair of the Day)
2. Plays or views → **likes** → **saves to collection**
3. **Shares** artist or pair link (OG preview)
4. New visitor lands → same loop

Instrument later: share taps, return visits, first upload, first tip.

## Invite week (20–50 creators)
1. Personal DM / email: why Kreatif (Sound & Sight + tips + one profile)
2. Ask for: complete profile (avatar + bio) + **3 uploads** minimum
3. Offer: feature on Home / Pair of the Day if they create 1 intentional pair
4. Collect feedback in one form (upload friction, discovery, tipping)

### Invite blurb (copy/paste)
> We’re building Kreatif — a home for original music *and* visual art, including pairs you can share as one link. Fans can like, collect, subscribe, and tip (10% platform fee). Would you publish 2–3 pieces and a short bio this week? Happy to feature strong pairs.

## Share checklist (smoke-test)
- [ ] `/` default title + description look right in page source
- [ ] Open `/artist/:id` → Share profile → paste in Notes / Discord (link works)
- [ ] Open `/content/:id` → Share → link opens work
- [ ] Open `/pair/:id` → Share → title shows “A × B — Kreatif Pair”
- [ ] Mobile: Share uses system sheet when available; otherwise copies URL

**Note:** Client-side `og:` tags help in-app and some crawlers; WhatsApp/iMessage previews work best with server-rendered meta (GitHub Pages limitation). Still ship accurate titles/URLs so copied links are trustworthy.

## Bio standard (artists)
Who + what → one vivid image → CTA. ~150–220 characters. See profile edit helper text.

## What not to chase yet
Avatar gamification, DMs, full social feed, Spotify-scale catalog. Activation + share + real roster first.

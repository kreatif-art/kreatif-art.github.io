# Befolk font files

Download **Befolk** (free brush script by Dirtyline Studio / Hendra Maulia):

- https://www.behance.net/gallery/52417399/Befolk-Free-Brush-Script-Font
- or search “Befolk free font” on Fontesk

Place one or more of these in this folder (same basename):

- `Befolk.woff2` (preferred)
- `Befolk.woff`
- `Befolk.ttf`
- `Befolk.otf`

Then rebuild / redeploy. The hero title uses `font-family: 'Befolk'`.
